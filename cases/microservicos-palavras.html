Microsserviços Palavras

Processamento de texto e organização de serviços em uma arquitetura de aprendizado.

Ver GitHub ↗Entrar em contato

Visão geral

Problema

Exercitar a separação de responsabilidades e a comunicação entre serviços aplicando conceitos de processamento de texto.

Abordagem

Projeto de estudo com APIs para operações sobre palavras e texto, organizado como prática de desenvolvimento de back-end.

O que foi desenvolvido

  • Estudo de estruturação de serviços
  • Prática com processamento de textos
  • Organização de contratos e lógica de API
  • Versionamento de código no GitHub

Estágio atual

Projeto de estudo com repositório público. A execução, os testes e o escopo implementado devem ser verificados no código.
